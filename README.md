# Gonkichi – 詰将棋ソルバー（Python）

Python で実装した詰将棋ソルバーです。  
深さ優先探索による詰み探索エンジンと、Tkinter を用いた簡易 GUI アプリケーションを含みます。

---

## 🔧 機能概要

- 深さ優先探索による詰将棋の詰み判定
- 王手・受け手の全探索
- 打ち歩詰めの判定に対応
- 手順の探索順序最適化（受け手の少ない順に並べ替え）
- Tkinter GUI による駒配置・手数入力・Solve 実行
- 性能：1秒間に約8000~10000手探索できます。(Core-i7)
- 性能：13手詰めくらいまでなら10分程度あればだいたい解けます。

---

## 🧠 エンジンの仕組み

本ソルバーは、攻め側（王手）と受け側（応手）が交互に指す詰将棋を  
深さ優先探索で再帰的に検証する構造になっています。

### 主な処理

- `searchOute()`  
  王手の候補手を生成

- `searchUke()`  
  受け側の応手を生成

- `__VerifyOuteCandidate()`  
  王手 → 受け → 王手… の再帰的検証  
  - 受け手が存在しない → 詰み  
  - 打ち歩詰めの判定  
  - MaxStep を超えた場合は不詰

- `__changeOrder()`  
  受け手の少ない順に並べ替え、探索効率を向上

探索結果は辞書構造で保持し、詰み手順の復元が可能です。

## 🖥️ Tkinter GUI

本プロジェクトには、盤面を操作できる簡易 GUI を同梱しています。

### GUI の機能

- マウス操作で駒を配置
  - クリック：駒選択・駒配置（盤上・駒台）
  - ダブルクリック：成⇔不成　切り替え（盤上）
  - 右クリック：先手⇔後手　切り替え（盤上）
- 手数の入力
- 「Solve」ボタンで探索開始
- 結果を表示
  - ▶：進む　◀：戻る
  - ▶▶：詰み局面へ　◀◀：初期状態へ
- コンソール出力：
  - 初手ごとに探索経過表示
  - 詰み手順の表示
- 詰将棋の保存・読み出し(pickle形式)
  - FILE→SAVE：盤面・手順の保存
  - FILE→LOAD：盤面・手順の読み出し
- 中合いモード：☑で玉の2マス手前の中合いを許可
- ゲームモード：詰将棋手動検討できます。
  - ☑するとルール上可能な移動しかできなくなります。
  - ▲や▼を☑すると先手・後手の駒の効きを表示します。
- おまけ：オリジナル詰将棋
　- gonkichi\pickle\オリジナル7手詰め.pickle　があります。LOAD機能でお試しください。
